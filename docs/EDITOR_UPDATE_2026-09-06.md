# 편집 편의 기능 및 번역 단축키 충돌 수정

- 번역 전역 단축키 등록과 설정 항목을 제거한다. 구버전 설정의 `translateCapture` 값은 무시하고 다음 저장 시 제거한다. 트레이의 `텍스트 + 번역`과 편집기 AI 도구의 번역 기능은 유지한다.
- 편집기 상단 `회전·반전` 메뉴에서 오른쪽/왼쪽 90°, 180° 회전, 좌우/상하 반전을 제공한다. 저장·복사·캡처 기록에 변환된 이미지가 반영된다. Ctrl+Z/Ctrl+Y로 실행 취소·다시 실행할 수 있다.
- 회전·반전할 때 그려둔 개체는 이미지에 합쳐진다. 실행 취소하면 원래 이미지와 편집 가능한 개체가 복원된다. 메뉴 버튼 도움말에도 이 동작을 안내한다.
- 펜, 형광펜, 도형, 화살표, 텍스트, 번호, 말풍선의 마지막 색상·굵기를 도구별로 기억한다. 새 캡처 및 앱 재실행 후 복원하며, 구버전 설정이나 유효하지 않은 저장값은 기본값을 사용한다.
- 설정 저장은 짧은 지연으로 연속 슬라이더 변경을 모으고, 창을 닫거나 설정을 열 때 즉시 반영한다. 관련 도구 설정만 갱신해 단축키와 창 크기 설정을 보존한다.
- 상단 작업 버튼과 그리기 도구를 두 줄로 분리한다. 도구는 아이콘과 이름을 함께 표시하며, 좁은 창에서는 보조 도구를 `더보기` 메뉴에서 선택한다. `크롭`의 표시 이름은 `자르기`로 바꾸고 사용법·단축키 도움말을 보강한다.
- 펜·형광펜, 모자이크·블러 등 편집 도구의 벡터 아이콘을 다듬어 형태를 구분하기 쉽게 한다.
- 편집기의 복사 버튼과 Ctrl+C는 현재 편집 결과를 PNG 이미지로 복사하면서 터미널에 바로 붙여넣을 수 있는 따옴표 처리된 절대 파일 경로도 함께 제공한다. PNG는 전용 임시 폴더에 보관하며 24시간이 지난 파일부터 정리한다.
- 네이버 프리미엄콘텐츠 `AI 실전 활용법` 안내를 편집기에서 더 크고 선명하게 표시해 관련 콘텐츠를 쉽게 찾을 수 있게 한다.

검증: Release 빌드와 전체 xUnit 테스트 249개 통과. 별도 WPF 검증 프로그램으로 색상/굵기 UI 변경 → 도구 전환 → 새 캡처 → 편집기 재생성, 회전 → 실행 취소/다시 실행 → 캡처 기록 재선택을 확인한다. 편집기 700/860/1100/1400px에서 이름 표시, 모든 도구 접근, 더보기 선택 표시, 복사·저장 버튼 잘림 여부와 단축키 설정 화면 렌더링을 확인한다.

이 문서는 v1.3.14 릴리스 후보의 편집기 변경 사항을 기록한다.
