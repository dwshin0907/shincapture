# 신캡쳐 v1.3.20

이번 버전은 **코드 서명이 없는 배포본**입니다. SignPath Foundation 승인을 기다리는 동안 공개하며, 승인 후 서명본은 새 버전으로 배포합니다. Windows에서 게시자 확인 또는 SmartScreen 경고가 표시될 수 있습니다. ZIP에도 동일한 미서명 설치 프로그램이 들어 있습니다. 파일 확인용 SHA-256 해시는 첨부된 `SHA256SUMS.txt`에 있습니다.

## 캡처 후 Ctrl+V: AI 터미널에는 경로, 카카오톡에는 이미지

- 캡처하면 이미지와 PNG 파일 경로를 함께 복사합니다. Codex, Claude Code 같은 AI 터미널에서 `Ctrl+V`를 누르면 캡처 파일 경로가 들어갑니다.
- PC 카카오톡 창으로 옮기면 클립보드를 이미지 전용으로 자동 전환해 대화창에 이미지로 붙습니다. 다른 창으로 돌아가면 경로가 포함된 형식으로 되돌립니다.
- 따로 누를 단축키나 고를 설정은 없습니다. `Ctrl+V`만 쓰면 됩니다.
- 캡처 직후 자동 복사, 편집기 `복사`·`Ctrl+C`, 기록 카드의 `클립보드 복사`, 빠른 저장 후 자동 복사에 모두 적용됩니다.
- 투명 배경은 PNG로 보존하고, 투명도를 지원하지 않는 프로그램을 위해 흰색 배경으로 합친 이미지도 함께 넣습니다.
- 그사이 다른 프로그램에서 새로 복사한 내용은 덮어쓰지 않습니다.

자동 전환은 프로세스 이름이 `KakaoTalk`인 Windows PC 카카오톡에만 적용합니다. 임시 PNG는 `%LOCALAPPDATA%\ShinCapture\Temp\Clipboard`에 저장하고 오래된 파일은 자동으로 정리합니다. 계속 보관하려면 저장 기능을 사용하세요.

전체 테스트 352개가 통과했습니다. 배포용 단일 EXE에서 클립보드 형식 생성과 창 감지 스레드의 시작·종료를 확인했습니다. 자세한 동작은 [클립보드 붙여넣기 설명](https://github.com/dwshin0907/shincapture/blob/v1.3.20/docs/CLIPBOARD_PASTE.md)에 있습니다.

Windows 10/11, 64비트. EXE를 실행하거나 ZIP을 풀어 안의 설치 파일을 실행하면 업데이트할 수 있습니다.
