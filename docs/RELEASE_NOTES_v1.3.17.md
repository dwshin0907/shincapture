# 신캡쳐 v1.3.17

## 이미지 파일 열기
- 편집기 상단 **열기**, **Ctrl+O**, 파일 드래그로 이미지를 불러올 수 있습니다.
- PNG, JPG, BMP, GIF, TIFF를 열어 모자이크·화살표·형광펜 등 기존 편집 도구로 수정하고 저장할 수 있습니다.
- 여러 파일을 한 번에 열면 캡처 기록에 추가됩니다. GIF/TIFF는 첫 장을 불러옵니다.

## 텍스트 워터마크
- 상단 **워터마크**에서 문구, 크기, 불투명도, 색상과 위치를 지정하고 미리보기로 확인할 수 있습니다.
- 넣은 워터마크는 이동·삭제·실행취소가 가능하며 저장과 복사에 포함됩니다.

## 선택형 한글 호환 단축키
- 기본 Ctrl+Shift+C 동작은 그대로입니다. 누르는 순서와 관계없이 캡처합니다.
- 필요한 분만 **환경설정 → 단축키 → 영역 캡처: Shift → Ctrl → C 순서로만 실행 (한글 호환)**을 켜주세요.
- 옵션을 켜면 Shift부터 누를 때 캡처하고, Ctrl부터 누를 때는 현재 프로그램으로 입력을 전달합니다. 영역 캡처에 Ctrl+Shift+C를 지정한 경우에만 적용됩니다.

Windows 10/11, 64비트. ZIP에는 설치 프로그램이 들어 있습니다.
