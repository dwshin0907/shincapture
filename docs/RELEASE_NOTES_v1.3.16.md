# 신캡쳐 v1.3.16

객체 자동 추출(스마트 컷)의 경계 품질과 취소·재시도 동작을 개선했습니다.

- 추출한 객체의 대각선과 모서리에 부분 투명도를 적용해 계단 현상을 줄였습니다. 원본 이미지 크기와 색상은 유지합니다.
- 미완성 올가미와 너무 작은 선택은 처리에 넘기지 않고 다시 그리도록 안내합니다. 시작점 근처에서 끝난 올가미는 자동으로 닫습니다.
- 추출 중에도 Esc 또는 마우스 오른쪽 버튼으로 취소할 수 있습니다. 취소 이후 완료된 작업은 편집기를 열지 않습니다.
- 배경을 구분하기 어려운 선택은 투명 올가미 결과로 대체하고, 큰 이미지의 분석 크기를 제한해 처리 부담을 줄였습니다.
- 연속 단축키 입력으로 캡처가 겹치거나 이전 작업의 정리가 새 캡처에 영향을 주지 않도록 보호했습니다.

객체와 배경의 색이 비슷하거나 윤곽이 복잡한 이미지의 추출 정확도는 이미지에 따라 달라질 수 있습니다.

설치파일을 실행하면 기존 버전을 업데이트할 수 있습니다. ZIP에는 같은 설치파일이 들어 있습니다.
