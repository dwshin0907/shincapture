# v1.3.20 로컬 재설치 기록

2026-10-18, 유지관리자의 PC에서 기존 앱을 제거하고 새로 설치하라는 요청에 따라 로컬 설치를 교체했다.

- 기존 설치: `C:\Program Files\ShinCapture`, v1.3.17.
- 새 설치: 같은 경로, v1.3.20. 프로젝트와 설치 스크립트의 버전을 함께 올렸다.
- 변경 기능: [캡처 후 Ctrl+V와 카카오톡 자동 전환](CLIPBOARD_PASTE.md).
- Inno Setup 설치 과정에서 기존 앱을 종료하고 이전 설치를 제거한 뒤 새 파일과 등록 정보를 구성했다. 설치 종료 코드는 0이며 Windows 재시작은 필요하지 않았다.
- 설정 파일은 설치 전후 SHA-256이 동일했다. 기존 자동 실행 설정과 바탕화면 바로가기를 유지했다.
- 설치된 EXE는 검증한 publish EXE와 SHA-256이 일치한다. 새 앱을 일반 사용자 권한으로 실행해 창 응답과 `MainWindow 생성 OK`, `Show() OK` 시작 로그를 확인했다.
- 이전 실행 파일·설정·제거 등록 정보와 설치 로그는 `%LOCALAPPDATA%\ShinCapture\Backups\Before-v1.3.20-20261018-190657`에 보관했다.
