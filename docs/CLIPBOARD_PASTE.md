# 캡처 후 Ctrl+V: 터미널 경로와 카카오톡 이미지 자동 전환

캡처 직후 `Ctrl+V`만 사용한다. 기본 복사는 이미지와 PNG 파일 경로를 제공하고, 카카오톡 창이 활성화되면 자동으로 이미지 전용 형식으로 전환한다. 다른 창으로 돌아가면 같은 PNG 경로를 복원한다. 추가 단축키나 수동 모드 선택은 없다.

자동 전환은 실행 프로세스 이름이 `KakaoTalk`인 Windows PC 카카오톡에만 적용한다. Codex·Claude Code·Antigravity를 포함한 다른 앱에는 기본 형식을 유지한다. 프로세스 제목으로 터미널이나 편집기를 추측하지 않는다.

## 적용되는 복사

- 캡처 직후 자동 복사
- 편집기 `복사` / `Ctrl+C`
- 기록 카드의 `클립보드 복사`
- 빠른 저장 후 자동 복사

자동 복사 설정이 꺼져 있으면 캡처·저장 시 복사하지 않는다. `캡처 후 → 클립보드만`은 기존대로 항상 복사한다. 편집 결과를 포함하며 OCR 텍스트·선택 텍스트 복사와 기록 패널의 기존 경로 복사는 유지한다.

기본 형식은 투명도를 보존하는 PNG, 흰색 배경으로 합성한 DIB/Bitmap, FileDrop, 따옴표로 감싼 한 줄 Unicode 경로다. 카카오톡 형식에는 PNG·DIB/Bitmap과 내부 세션 식별값만 제공하며, 텍스트와 FileDrop은 제공하지 않는다. 경로에 줄바꿈을 포함하지 않는다.

임시 PNG는 `%LOCALAPPDATA%\ShinCapture\Temp\Clipboard`에 저장한다. 최신 경로는 다음 이미지·경로 복사까지 정리에서 보호하며, 다른 임시 파일에는 24시간·100개·250MB 정리 기준을 적용한다. 영구 보관하려면 저장을 사용한다.

## 자동 전환 보호

전용 메시지 루프에서 Windows foreground 이벤트를 받는다. 최초 복사와 재시도에서도 현재 활성 프로세스를 다시 확인한다. 이미지 인코딩과 파일 쓰기는 별도 작업 스레드에서 수행하며, 앱 전환 때는 같은 PNG와 DIB 캐시를 사용한다.

자동 교체는 Windows 클립보드를 잠근 뒤 sequence·소유 창·세션 식별값·캡처 세대를 검사한다. 다른 내용을 복사했거나 더 최신 캡처가 대기 중이면 이전 데이터의 자동 교체를 중단한다. 잠금 경합은 최대 250ms 동안 20ms 타이머로 재시도하며, 그때마다 현재 앱을 다시 확인한다. 키보드 입력을 가로채거나 재전송하지 않는다.

Windows가 `CloseClipboard`에서 합성 형식을 추가해 sequence를 다시 증가시키므로, 게시 완료 후 번호를 기록한다. 이후 잠금 안에서 소유 창과 세션 식별값도 함께 검사해, 번호 기록 직전에 다른 앱이 복사하더라도 덮어쓰지 않는다. 자동 전환에 한해서 클립보드 기록 제외 형식을 제공해 같은 캡처의 반복 기록을 줄인다.

## 설계 검토와 확인 범위

사용자 요청에 따라 Astra에 실제 자문했다. 초기의 별도 이미지 복사 권고는 사용자가 `Ctrl+V`만 사용하고 카카오톡만 자동 감지하길 확정한 뒤 수정했다. 카카오톡 예외만 적용하는 범위, 데이터 소유권 보호, 전용 메시지 루프, 재진입과 종료 처리에 대한 검토를 반영했다.

자동 테스트는 앱 전환·역전환, 이미 활성화된 카카오톡에서의 최초 복사, 타사 복사, 세션 식별값 불일치, 잠금 경합, 오래된 이벤트·캡처 무효화, 부분 실패, 감지 스레드 시작·종료, Unicode 경로, PNG 투명도, DIB 행 정렬·흰색 배경을 확인한다. 별도 Windows 클립보드 검증 프로그램으로 실제 PNG/DIB/합성 Bitmap을 읽고 이미지 전용↔경로 포함 형식 30회 전환 및 오래된 sequence 거부를 확인했다. 검증 전 클립보드 내용은 메모리에서 보관하고 완료 후 복원했다.

Release 빌드와 전체 테스트 352개가 통과했다. 3840×2160 합성 그라데이션 이미지의 단일 계측은 PNG 인코딩·파일 쓰기 122ms, PNG 재읽기·DIB/경로 캐시 준비 89ms, 기본 클립보드 게시·결과 확인 18ms, 캐시를 이용한 카카오톡 형식 전환·텍스트 부재 확인 33ms였다. 이미지 생성과 화면 캡처는 이 계측 범위에 포함하지 않았다.

카카오톡의 실제 붙여넣기 화면과 각 AI 터미널의 첨부 인식은 별도 사용자 환경 확인 대상이다. foreground 알림은 비동기이므로 앱 전환과 붙여넣기가 극단적으로 겹치면 전환 전 형식을 읽을 가능성이 있다. PNG 준비가 끝나기 전 붙여넣으면 이전 클립보드를 읽을 수 있다. 경로를 다른 컴퓨터의 SSH 경로나 WSL 경로로 자동 변환하지 않는다.
