# 신캡쳐 v1.3.18

## 캡처 기록 다중 선택
- 우측 캡처 기록의 체크박스 또는 Ctrl+클릭으로 여러 장을 선택할 수 있습니다.
- Shift+클릭으로 범위를 선택하고, **전체 선택**으로 한 번에 선택하거나 해제할 수 있습니다.
- 선택한 개수를 패널 상단에서 확인할 수 있습니다.

## 선택한 캡처만 저장
- **선택 저장**으로 필요한 이미지만 원하는 폴더에 PNG로 저장합니다.
- 현재 캡처와 이전 캡처의 편집 내용을 모두 반영합니다. 기존 **전체 저장**도 편집 내용을 포함합니다.
- 반복 저장 시 기존 파일을 덮어쓰지 않습니다.

## 터미널에 이미지 경로 한꺼번에 전달
- 선택한 썸네일을 터미널이나 다른 앱으로 끌면 선택된 이미지들을 함께 전달합니다.
- **경로 복사**로 여러 이미지의 경로를 한 번에 복사해 붙여넣을 수도 있습니다.
- 한글·공백이 있는 경로를 지원하며, 여러 파일을 준비하는 동안 임시 파일이 정리되지 않도록 보호합니다.

Windows 10/11, 64비트. ZIP에는 설치 프로그램이 들어 있습니다.
