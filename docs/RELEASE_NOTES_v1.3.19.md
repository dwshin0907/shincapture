# 신캡쳐 v1.3.19

이번 버전은 **코드 서명이 없는 배포본**입니다. SignPath Foundation 승인을 기다리는 동안 공개하며, 승인 후 서명본은 새 버전으로 배포합니다. Windows에서 게시자 확인 또는 SmartScreen 경고가 표시될 수 있습니다. ZIP에도 동일한 미서명 설치 프로그램이 들어 있습니다. 파일 확인용 SHA-256 해시는 첨부된 `SHA256SUMS.txt`에 있습니다.

## 모자이크 오류 수정

- 일부 이미지에서 모자이크 색상이 달라지거나 불투명한 영역이 투명해지는 문제를 수정했습니다.
- 이미지의 픽셀 형식과 투명도를 올바르게 처리합니다.
- 모자이크를 옮기거나 크기·강도를 바꿀 때 필요한 영역만 처리하고, 바뀌지 않은 그리기 결과는 재사용합니다.

## OCR 처리 개선

- 문자 인식 전에 불필요하게 PNG로 압축하고 다시 읽던 과정을 제거했습니다.
- 인식에 사용하는 이미지 자원이 완료·실패 후 즉시 해제되도록 보완했습니다.

## 설치 파일 약 10% 감소

- 사용하지 않는 영상 입출력 DLL을 제외해 설치 파일이 **108.2MB에서 97.3MB**로 줄었습니다.
- .NET이 포함된 배포 방식과 스마트 컷 기능은 유지합니다.

같은 PC의 4K 이미지 비교에서 모자이크 영역 이동 시 그리기 명령 준비는 약 13.8ms → 1.6ms, OCR 입력 이미지 준비는 125ms → 13.8ms였습니다. 해당 처리 구간의 측정치이며 전체 화면 표시나 실제 문자 인식 시간은 포함하지 않습니다.

전체 테스트 330개, 영상 DLL을 제외한 환경의 스마트 컷·OCR 테스트 24개가 통과했습니다. 배포용 단일 EXE의 스마트 컷 실행과 편집기 화면·선택 저장도 검증했습니다. 자세한 조건은 [성능 검증 보고서](https://github.com/dwshin0907/shincapture/blob/v1.3.19/docs/PERFORMANCE_AUDIT_v1.3.19.md)를 참고하세요.

Windows 10/11, 64비트. ZIP에는 설치 프로그램이 들어 있습니다.
