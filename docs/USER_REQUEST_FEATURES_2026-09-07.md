# 사용자 요청 반영 (Windows)

## 한글 호환 단축키 옵션

- 환경설정 → 단축키 → **영역 캡처: Shift → Ctrl → C 순서로만 실행 (한글 호환)**.
- 기본값은 **끔**. 기존 설정 파일에서도 끔으로 시작하며 Ctrl+Shift+C는 누른 순서와 무관하게 캡처한다.
- 켜면 영역 캡처의 주/보조 단축키가 Ctrl+Shift+C인 경우에만 순서를 구분한다. 다른 조합에는 영향을 주지 않는다.
- Shift를 누른 채 Ctrl을 누르고 C를 누르면 캡처한다. Ctrl부터 누른 조합은 현재 앱으로 전달한다. 한글 실행 여부를 검사하지 않으므로 다른 앱에도 동일하게 적용된다.
- 왼쪽/오른쪽 Ctrl·Shift를 모두 지원하며 반복 입력은 한 번만 실행한다. Alt·Windows 키가 섞인 조합은 가로채지 않는다.
- 설정창에서는 캡처를 일시 중단한다. 설정 취소 시 복원하고 저장 시 다시 등록한다.
- 호환 모드에서는 해당 조합을 RegisterHotKey로 독점하지 않는다. 별도 메시지 스레드의 WH_KEYBOARD_LL에서 순서를 판별하고 캡처는 UI 스레드에 예약한다. 이 구조는 [Microsoft의 LowLevelKeyboardProc 지침](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)에 따라 콜백 지연을 줄인다.
- 한글 실제 편집창에서 가운데 정렬과 영역 캡처를 확인하는 수동 검증은 아직 필요하다. 다른 프로그램이 같은 조합을 전역 등록한 경우 그 프로그램의 동작까지 제어하지는 않는다.

## 텍스트 워터마크

- 편집기 상단 **워터마크** → 문구, 글자 크기, 불투명도, 흰색/검정, 9개 위치 지정 → 미리보기 → **넣기**.
- 긴 문구는 이미지 안에 들어가도록 축소한다. 마지막으로 적용한 값은 설정에 저장한다.
- 편집 개체로 추가하므로 선택 도구로 이동·삭제할 수 있고 실행취소/다시실행이 가능하다.
- 저장, 클립보드 복사, 드래그 내보내기에 포함된다. 취소하면 이미지에 추가하지 않는다.
- 이번 구현은 텍스트 워터마크다. 로고 파일 워터마크나 모든 캡처에 자동 적용하는 기능은 포함하지 않는다.

## 이미지 파일 열기

- 편집기 상단 **열기**, **Ctrl+O**, 또는 외부 이미지 파일을 편집기 창에 드롭한다.
- PNG, JPEG, BMP, GIF, TIFF를 지원하며 여러 파일을 선택할 수 있다. 최대 50개씩 기록에 추가한다.
- GIF는 첫 프레임, TIFF는 첫 페이지만 연다. 카메라 EXIF 방향을 반영한다. 8천만 화소를 초과하면 열지 않는다.
- 기존 모자이크·화살표·형광펜·워터마크 도구로 편집하고 저장/복사할 수 있다. 불러오기 자체는 원본 파일을 수정하지 않으며 파일 잠금을 유지하지 않는다.
- 앱 내부 기록의 내보내기 드래그는 다시 불러오지 않는다. 지원하지 않거나 손상된 파일은 알리고 다른 선택 파일은 계속 연다.

## 검증

- 단축키 순서·기본값·좌우 키·반복·중단·추가 수정자, 네이티브 훅 수명, 설정 저장, 워터마크 위치/불투명도/내보내기/실행취소, 이미지 형식/파일 잠금 회귀 테스트.
- Release 솔루션 빌드 및 전체 테스트.
- 비대화형 WPF 렌더링으로 860×620, 1440×850 편집기, 워터마크 대화상자, 단축키 설정 화면 확인.
- 실제 편집기 불러오기 메서드에 PNG를 전달해 이미지 교체와 편집 개체 초기화를 확인.
- 로컬 검토 이미지: `publish/feature-review/output/` (배포/커밋 대상 아님).

정식 릴리스 절차는 `docs/RELEASE_PIPELINE.md`를 따른다.
