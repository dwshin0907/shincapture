# 캡처 기록 다중 선택과 일괄 내보내기

- 우측 썸네일의 체크박스 또는 Ctrl+클릭으로 여러 장을 선택한다. Shift+클릭은 범위를 선택한다.
- 일반 클릭은 한 장을 선택해 편집기에 연다. 여러 장이 선택된 상태에서 썸네일을 누르고 바로 끌면 선택이 유지된다.
- `전체 선택`은 전체 선택과 선택 해제를 전환한다. 선택 개수는 패널 상단에 표시된다.
- `선택 저장`은 선택한 캡처만 지정한 폴더에 PNG로 저장한다. `전체 저장`은 전체 기록을 저장한다. 두 기능 모두 편집 내용을 포함하며 기존 파일을 덮어쓰지 않는다.
- 선택된 썸네일을 터미널이나 외부 앱에 드래그하면 선택한 모든 이미지가 목록 순서로 전달된다. Windows 파일 목록과 각 경로를 따옴표로 감싼 한 줄 텍스트를 함께 제공한다. 자동 실행을 유발하는 줄바꿈은 넣지 않는다.
- `경로 복사`는 동일한 파일 경로 텍스트를 복사한다. 드롭을 받지 않는 입력창에서도 붙여넣기로 사용할 수 있다.

기록 목록에 키보드 포커스가 있을 때 Ctrl+A는 전체 선택, Space는 선택 전환, Shift+↑↓는 범위 선택, Ctrl+↑↓는 포커스 이동, Ctrl+Shift+C는 경로 복사다. 일반 ↑↓는 한 장씩 선택해 연다.

드래그·경로 복사는 `%LOCALAPPDATA%\ShinCapture\Temp\DragDrop`의 임시 PNG를 사용한다. 편집기에서 보관 중인 준비 파일과 진행 중인 일괄 작업의 파일은 캐시 정리로 삭제되지 않도록 보호한다. 보호가 끝난 파일에는 기존 보존 기간·개수·용량 제한이 적용된다. 영구 보관은 `선택 저장`을 사용한다.

## 검증

- 선택 추가·해제, 범위 확장·축소, 목록 순서, 기록 정리, 회전·반전 시 선택 유지: `CaptureHistorySelectionTests`
- 여러 파일과 한 줄 Unicode 경로 전달, 캐시 제한 아래 묶음 보존, 선택 파일만 저장, 재저장 시 덮어쓰기 방지, 부분 실패 처리: `HistoryExportBatchTests`, `DragExportServiceTests`
- 편집 개체 합성: `EditorCompositeRendererTests`
- 900×720 및 1500×900 WPF 렌더링, 체크박스·전체 선택 이벤트, 현재/이전 캡처 편집 결과 저장을 별도 로컬 검증 프로그램으로 확인했다.
- Windows 화면 제어 도구의 `native pipe unavailable` 오류로 실제 터미널에 마우스로 드롭하는 종단 검증은 수행하지 못했다. 전달 데이터 형식은 자동 테스트로 확인했다.
